# Public release and transformation policy

This is a separate derived release with fresh Git history. The original
experiment repository and its immutable captures remain private.

The public dataset is a strict field projection. It retains model labels,
scientific settings, source content digests, saved scalar timing/calibration
observations, reported correctness flags, research outcomes and aggregate cost
estimates. It uses generic experiment roles such as final board and diagnostic
board. It excludes personal/work email, local usernames and hostnames, machine
paths, cloud projects, accounts and service identities, IPs, hardware UUIDs, cloud
resource/image/application IDs, nonces, API request IDs, credentials, native
provider states, conversations, administrative operations and raw logs.

Administrative receipts and historical engineering exports are omitted rather
than transformed into apparent raw evidence. Candidate and upstream task code
are omitted under the licensing policy. The public paper is rebuilt from clean
LaTeX, and the source ZIP is assembled exclusively from an explicit public
allowlist. Old PDFs, ZIPs and Git objects are not carried into this repository.
PDF information/XMP/attachments are removed during generation. Required public
upstream attribution and public dependency identifiers remain intact.

Public dataset digests and release hashes are newly generated. Original source
content digests are retained as non-expressive commitments; they do not grant
access to or a license for the private source bodies. The transformation
manifest records the release's projection scope without a private path map.
The private operator keeps the detailed source-to-projection map separately.

The public CPU replay reconstructs saved numerical statistics. A passing replay
does not authenticate the original GPU events, re-execute source review, rerun
correctness, or verify private cloud administration. These limits are stated in
the report and dataset. No new GPU runs or model calls were made for this export.

The release audit checks text, JSON, PDF text/metadata and ZIP members, excluded
source-body digests, Git author identity and fresh history. Its receipt reports
counts and checks; it does not publish the removed identifiers. Pattern scans
cannot prove the absence of every conceivable secret, so this release also
uses a narrow input allowlist and excludes administrative source material.
