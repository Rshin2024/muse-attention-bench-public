# Public scientific projection

`results.json` retains the seven selected first measurements on a common final
GPU, two baseline controls, all numeric oracle observations, raw calibration
samples, AB/BA replay brackets, reconstructed load scores and intervals. Four
models delivered authored kernels. Three retained the supplied starter; its
observations receive no model optimization performance point.

`profile.json` contains numeric shape and timing facts. The `protocol_sha256`
inside each result commits to the original experiment protocol; it is not the
digest of this smaller public fact projection. Candidate hashes are source
commitments only. Candidate and third-party task bodies are omitted, and static
source-review decisions are reported facts that cannot be re-reviewed here.

`manifest.json` records the field allowlist policy, record counts, public file
hashes and a hash commitment to the operator-normalized input. It contains no
original input paths or resource identities. Original hash-bound evidence stays
private. This public projection does not claim to preserve raw producer bytes or
replay the private cloud-resource provenance gate.

From the repository root, run:

```sh
python3 scripts/reproduce_results.py
```

This reconstructs all nine scalar reports without API keys, third-party task
files, candidate execution, a GPU, or network access. It checks saved data
consistency; it does not perform a new correctness or performance experiment.
Known costs are estimates, unresolved reserves are not confirmed charges, and
unobserved fees and credits remain explicit.
